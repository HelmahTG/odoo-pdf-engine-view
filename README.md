# Odoo PDF Engine Module

**Version:** 1.0  
**Author:** Helmah  
**License:** LGPL-3

## Overview

This Odoo module integrates a **custom PDF Engine** that allows users to upload and review **large drawing PDF files** inside Odoo. It is designed for industries that work with architectural and engineering blueprints.

## Features

- Upload large **PDF drawings** into Odoo.
- View PDFs inside Odoo without downloading.
- Works seamlessly with **Odoo 16+**.

## Installation

1. Install this module from the **Odoo App Store** or upload it manually.
2. Activate developer mode in Odoo.
3. Go to **Apps → Install PDF Viewer Module**.
4. Start using the PDF viewer inside Odoo!
